# Plans and designs

These dated plans and specifications record feature intent and implementation
history. Some contain unchecked tasks, old framework versions, or instructions
for tools used when they were written. Those details do not establish current
implementation status or a required agent workflow.

Use a relevant document to recover intent, then check the current source,
migrations, and tests. Repository constraints live in [AGENTS.md](../../AGENTS.md).
When resuming a plan, reconcile its remaining work with the user's current scope.

New plans should state the outcome, constraints, unresolved decisions, and
acceptance evidence. Include sequencing where dependencies require it; choose
implementation details during the work. Create a plan when it helps coordinate
a substantial change or the user requests one.
